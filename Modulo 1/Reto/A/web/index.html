Por que fetch() es tan distinto: el "grupo de control" no es injusto, es el punto de comparacion. fetch() pasa por el interprete de JavaScript, el stack HTTP del navegador, el bucle de eventos, TCP (con su propio handshake y control de flujo) y recien despues llega al mismo localhost. Cada una de esas capas agrega latencia que ni UDP crudo ni la memoria compartida tienen que pagar. Esa es, en una sola pantalla, la diferencia entre un plano de control (comodo, con HTTP y JSON) y un plano de datos critico (minimalista, a proposito).
