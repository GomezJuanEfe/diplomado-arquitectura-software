## Hilo conductor

1. **Qué es la nube**: características, modelos de servicio y despliegue, y por qué se adopta.
2. **Cómo se construye para la nube**: microservicios, contenedores, Kubernetes, serverless, CI/CD e IaC.
3. **Con qué metodología**: DDD → desarrollo → ejecución → plano de control → **observabilidad**.
4. **Cómo se comunican los servicios**: síncrono/asíncrono, brokers y resiliencia.
5. **Cómo se exponen al mundo**: API Gateway, Microgateway, Service Mesh y BFF.

> **Relación con el reto del Módulo 4 (observabilidad)**: la observabilidad aparece como capacidad de la gestión dinámica (logs, métricas y trazas con control centralizado) y como fase final de la metodología cloud native: entender el estado del sistema sin desplegar código nuevo.
